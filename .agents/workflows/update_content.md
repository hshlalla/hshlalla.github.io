---
description: Workflow for adding a new AI/Sound research post.
---

1. Create a new markdown file in `_posts/` using the format `YYYY-MM-DD-title.md`.
2. Add necessary Front Matter:
   ```yaml
   layout: single
   title: "Title"
   categories:
     - Deep Learning
     - Sound
   tags:
     - tag1
   last_modified_at: YYYY-MM-DD
   ```
3. Use high-quality placeholders or images generated by AI if needed.
4. Ensure the content follows the "premium" tone defined in `instructions.md`.
