# AI Agent Instructions: Sound of DeepLearning Project

## Project Context
`hshlalla.github.io` is a Jekyll-based personal portfolio and blog focusing on **Sound, Music, and Deep Learning**. The goals are:
1. To showcase technical expertise in AI and sound engineering.
2. To provide a "Work Dashboard" for the user to manage their AI-related business and development.

## Aesthetic Standards (CRITICAL)
- **Style**: Premium, Futuristic, Agentic.
- **Visuals**: Use Glassmorphism (blur: 10px, semi-transparent backgrounds).
- **Colors**: Deep dark backgrounds (`#0a0a0c`) with vibrant accents (Electric Purple, Neon Cyan, Hot Pink).
- **Typography**: Modern, sans-serif (Inter, Roboto, or Outfit).
- **Transitions**: Smooth fade-ins and scale animations for all interactive elements.

## Coding Standards
- **CSS**: Use SCSS in `_sass/`. Favor variables for colors and spacing.
- **JS**: Minimal, high-performance vanilla JavaScript. Use CDN-based libraries if necessary (e.g., GSAP for complex animations).
- **Mobile First**: All UI changes must be responsive.

## Agent Behavior
- Always prioritize "WOW" factor in UI design.
- Avoid using standard Minimal Mistakes components for the homepage; instead, build custom, dashboard-like modules.
- **Automation Focus**: Be prepared to handle automated tasks such as summarizing technical news (AI Times) and processing document uploads.
- **OpenClaw Context**: Support future integration with OpenClaw AI for advanced document handling and autonomous task execution.
- Maintain a technical yet creative tone in content.
